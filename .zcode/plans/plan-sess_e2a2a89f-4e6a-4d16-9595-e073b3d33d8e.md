# State Audit — Findings (answer to the TODO)

Verified across `state.rs`, `engine.rs`, `job.rs`, both GUIs, and greps over all four crates. The snapshot is deep-cloned and republished every 40 ms tick (engine.rs:742-744), so every dead field is paid on every publish.

## 1. Necessity — dead / misplaced fields
- `generation` — bumped every tick (engine.rs:743), read by **nobody** (one test asserts it's 0, state.rs:500).
- `wake_lock_active` — only write ever is `= false` (engine.rs:939); both GUIs render a status chip that can never activate (ltc-gui status.rs:27, slint poll.rs:194).
- `ltc_decode_is_video` — write-only: 6 write sites, zero readers anywhere.
- `trim_enabled` — **no-op toggle**: pipeline fully supports trimming (args.rs, keyframe snapping runner.rs:409-428) but `assemble_converter_settings` hardcodes `trim_offsets_secs: vec![0.0; n]` (engine.rs:2019). User decision: **remove**.
- `naming_pattern` — **decorative**: scan always uses `match_files_all_patterns` (engine.rs:154); no GUI reads the field; Slint selector is UI-local, never synced. User decision: **remove**.
- `output_preview` / `encoder_chain_desc` — published by `recompute_converter_derived`, zero GUI readers (egui recomputes both locally from its edit buffer, converter.rs:1608/1432). The duplicate-output-warning only needs the preview as a local inside recompute.
- `system_time` — only egui reads it; Slint formats its own via the same `chrono_now_string()` helper (poll.rs:55).
- `use_libltc` — engine already receives it as an `engine_main` parameter (engine.rs:36); snapshot copy is a second source.
- `audio_initialized`, `ltc_decode_generation`, `probes_generation` — engine-internal working state; GUIs never read them (probes_generation's "so GUIs can discard stale results" doc is stale).
- `decode_fps` / `decode_drop_frame` — mechanically derived from `decode_fps_index`; only engine reads them (decode spawn sites).
- `JobOutcome::Succeeded.summary` — always constructed `String::new()` (job.rs:654-657), never destructured.
- Dead local `_suggest_sr_index` in `initial()` (state.rs:260-263).
- `SdCardInfo.pattern_name` / `MatchedGroup.pattern_name` — set-only outside tests (grep verified); remove, fall back to keep+document if a reader surfaces mid-refactor.
- Slint reads `offload.durations_version` (poll.rs:547) into a property **no `.slint` file consumes** — dead end-to-end.

## 2. Grouping / duplication
- **FPS triple ×2**: `fps_index`+`fps`+`drop_frame` and the decode twin — index plus two fields re-derived in lockstep at every write site (engine.rs:992-998, 1089-1096).
- **Group decode = 3 parallel Vecs** (`ltc_group_paths/results/errors`) aligned only by doc comments; hand-rolled Result invariant maintained in 3 places.
- **Flat top level with comment banners**: the 10-field LTC-decode cluster and clapper cluster sit loose while converter/offload got sub-structs.
- `file_durations` published twice (top-level + offload) — scopes genuinely differ (converter vs offload files); keep, document the split.
- `status_message` overlaps `jobs[kind].message/error`, `ltc_decode_error`, `offload.error`, `AudioEvent::StreamError` — one failure can surface in 3-4 places; 34 write sites.
- Readiness trust inverted: engine publishes `converter.readiness`, only Slint reads it; egui recomputes locally (converter.rs:1709).
- egui-local duplicates: `ltc_file_idx` (app.rs:163 — second copy beside `local_settings.ltc_file_idx`) and `selected_folder` (app.rs:168 — engine's `groups_folder` unread by egui).

## 3. Types
- `ltc_channel`/`beep_channel: String` — 3-value domain ("left"/"right"/"both") as strings through command.rs → engine → audio-core; a typo compiles.
- `selected_device: usize` — index into a volatile `Vec`; `AudioDeviceInfo.id: String` exists and the engine already tracks `last_device_id` to cope with re-scans.
- `ClapLogItem` — all-String, incl. `id` as a stringified counter; `timecode`+`milliseconds` are two formats of the same lost `Timecode`.
- `JobStatus` duplicates `ProgressSnapshot` field-for-field (job.rs:254-274) — composition removes the mirror.
- `LtcQualityReport.grade: String` — 5-value enum as a string.
- f64 vs f32 fps across snapshot/decoder: accepted, not worth churn.

# Implementation Plan (3 phases, each tested + separately committed)

Per AGENTS.md: tests updated/added first where behavior is observable; `cargo test --workspace && cargo clippy --all-targets` after every step; build both GUIs (`cargo build -p ltc-gui -p ltc-slint`); run touched tests under `cargo nextest run --retries 10` before committing.

## Phase 1 — Delete dead weight (mechanical)
1. Remove `generation` (+ engine.rs:743 increment, state.rs test).
2. Remove `wake_lock_active` + both GUI status chips/properties.
3. Remove `ltc_decode_is_video` (+ its 6 write sites, engine.rs tests 2949/2976).
4. Remove `trim_enabled` + `ConverterCommand::SetTrimEnabled` (command.rs, engine.rs:220) + egui merge rows (app.rs:350, 405-406) + test fixtures.
5. Remove `naming_pattern` + `SetNamingPattern` + Slint `conv-selected-pattern` property, its ui/app.slint selector and main.rs wiring.
6. Unpublish `output_preview`/`encoder_chain_desc`: recompute derives the duplicate warning from a local preview; delete egui's redundant *published*-field expectations (egui local recompute stays).
7. Remove `system_time`; egui formats locally via `timecode::chrono_now_string()` (same as Slint today).
8. Remove `use_libltc` from snapshot (engine keeps its existing param; cli.rs:852 stops setting it).
9. Remove `JobOutcome::Succeeded.summary`, `_suggest_sr_index`, `SdCardInfo.pattern_name`, `MatchedGroup.pattern_name`, Slint's dead `durations_version` property plumbing.
10. Doc fixes: stale `probes_generation` comment, offload.rs:190 stale comment, document `beep_duration` as seconds.

## Phase 2 — Type upgrades
1. New `ChannelSel { Left, Right, Both }` (gui-engine, re-exported; audio-core config takes the enum, CLI `--channel` parses into it). Replace `ltc_channel`/`beep_channel`, `GuiCommand::SetLtcChannel/BeepChannel`, both GUIs' pill/routing widgets, defaults left/right.
2. FPS accessors: stored truth = `fps_index`/`decode_fps_index` only; add `AppStateSnapshot::fps()/.drop_frame()/.decode_fps()/.decode_drop_frame()` deriving from `FPS_OPTIONS`; delete the 4 stored derived fields; engine derives locals at use sites (incl. native-TC fallback engine.rs:1933-1934); update GUI reads (`s.fps` → `s.fps()` etc.).
3. Group decode: replace `ltc_group_results`+`ltc_group_errors` with `Vec<ClipDecodeState>` (`Pending` | `Done(Result<LtcDetectionResult, String>)`), keep `ltc_group_paths`; update the 3 invariant sites (engine.rs:602-619 etc.) and egui converter.rs:501-509.
4. `JobStatus` becomes `{ progress: ProgressSnapshot, error: Option<String> }` with thin accessor methods (`fraction()`, `message()`, `log()`, `speed()`, `units()`, `phase()`) so GUI call-sites barely change.
5. `ClapLogItem.id: String` → `u64`; keep pre-formatted strings, documented as presentation convenience.
6. `LtcQualityReport.grade` → enum with `Display` (audio-core; CLI printing updated).

## Phase 3 — Regrouping + demotions
1. New `DecodeSnapshot` sub-struct: `decode_fps_index`, `ltc_probe`, `ltc_selected_stream/channel`, `ltc_decode_result`, `ltc_decode_error`, group paths/results/generation. Mechanical field-path updates in both GUIs.
2. New `ClapperSnapshot`: scene/take/roll/auto_increment/logs/flash_alpha/arm_angle/animating.
3. Demote engine-internal fields out of the snapshot into engine loop-locals: `audio_initialized`, `ltc_decode_generation`, `probes_generation` (the engine already keeps latch counters like `last_auto_applied_ltc_gen`).
4. egui duplicate cleanup: delete app.rs `ltc_file_idx` (use `local_settings.ltc_file_idx` only) and `selected_folder` (read `converter.groups_folder`).
5. Document `file_durations` dual-scope rationale at both sites.
6. Last, isolated commit: `selected_device: usize` → `Option<String>` device id; GUI combos resolve id→index per frame; engine matches by id (replaces `last_device_id` coping). Independently revertable if it proves disruptive.

## Explicitly out of scope (recorded as follow-ups)
`status_message` consolidation into per-subsystem channels; publish-gating (skip store when snapshot unchanged) as a perf pass; `file_durations` unification; `events` mailbox redesign; web/Tauri frontends (untouched — legacy).

## Definition of done
All phases committed separately; `cargo test --workspace` green, `cargo clippy --all-targets` warning-free on workspace lints, both Rust GUIs compile and run; `ltc-gui` manual smoke: play/stop, clap, device switch, convert tab readiness, offload tab; snapshot struct contains no field that is unread or engine-internal without documentation saying so.
